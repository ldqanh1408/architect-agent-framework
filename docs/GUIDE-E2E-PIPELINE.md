# Current end-to-end workflow

Read source and accepted grants. Register owners, clauses, artifacts, and obligations. Prepare bounded tasks with declared writes and dependencies.

Wait for required human dispatch gates. Claim one ready attempt. Submit isolated candidate operations with exact revisions. Run deterministic checks and independent semantic review.

The person reads exact evidence and signs document acceptance. The host publishes accepted bytes. Recovery preserves conflicting user edits.

Task checks, review, acceptance, and publication have separate states. A checked candidate does not qualify a release.

Use [the core guide](GUIDE-SDD-CORE.md) and [the run guide](GUIDE-CORE-RUNS.md). Old documents require a separate migration destination. No runtime workflow fallback exists.
