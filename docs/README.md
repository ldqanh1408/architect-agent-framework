# `docs/`

Reference for the Architect Agent Framework. The plugin's commands are described in
[the plugin README](../README.md).

| Document | Use it when |
|---|---|
| [`GUIDE-CORE-RUNS.md`](GUIDE-CORE-RUNS.md) | You run bounded tasks and review their exact evidence |
| [`GUIDE-E2E-PIPELINE.md`](GUIDE-E2E-PIPELINE.md) | You prepare isolated candidates and obtain independent review and signed acceptance |
| [`GUIDE-SDD-CORE.md`](GUIDE-SDD-CORE.md) | You use a revision-bound core workspace, external skills and signed candidate acceptance |
| [`CONCEPTS.md`](CONCEPTS.md) | You need the current meaning of artifact, obligation, task, gate, and acceptance |
| [`REFERENCE-CLI.md`](REFERENCE-CLI.md) | You look up current task, proposal, migration, or maintainer commands |
| [`REFERENCE-GATES.md`](REFERENCE-GATES.md) | You look up a gate or a finding code (generated; do not edit) |
| [`EVALUATION-AND-LANGUAGE.md`](EVALUATION-AND-LANGUAGE.md) | You run a bounded model pilot or an advisory language assessment |
| [`TROUBLESHOOTING.md`](TROUBLESHOOTING.md) | A terminal prints an error and you need to know what to do |
| [`RELEASE-STABILIZATION.md`](RELEASE-STABILIZATION.md) | You prepare, qualify and promote exact candidate bytes |
| [`samples/`](samples/) | You want a sample checklist, context file, module charter or page class |
| [`QUICKSTART-USE-CASES.md`](QUICKSTART-USE-CASES.md) | You want the 8 end-to-end use cases (`UC-01..08`) and all 16 slash commands across Claude, Codex, and DeepSeek Harness |
