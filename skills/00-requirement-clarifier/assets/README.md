# Assets

Markdown templates for Requirement Clarifier outputs.

## Templates

- [clarified-requirements-template.md](clarified-requirements-template.md) - Structure of the clarified-requirements.md output (interview log, CLR table, assumption register, open questions).
- [interview-question-bank.md](interview-question-bank.md) - Fixed-order question groups the interview draws from, scaled by complexity tier.
