# Living Requirement Update

Use the exact user-supplied requirement Markdown as the living Phase 0 source.

1. Read the complete current file and verify its recorded digest.
2. Ask one cohesive ambiguity group.
3. Capture the user's answer verbatim in the clarification ledger.
4. Replace exactly one current clause or append a new stable `URD-xxx`; never rewrite unrelated prose.
5. Record before/after SHA-256 and rescan the complete file.
6. Ask again while any ambiguity, contradiction, open question or unconfirmed default remains.
7. Finalize only after zero findings and explicit confirmation of the current digest.

If the source changed outside the transaction, preserve that edit and rescan instead of overwriting it.
