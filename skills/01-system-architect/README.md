# System Architect Skill

Translates business problem statements and functional requirements into comprehensive architectural specifications.

## Folder Directory Structure

- [SKILL.md](SKILL.md) - Deep guidelines, capabilities, and trigger rules.
- [agents/](agents/) - AI config stubs defining agent prompts.
- [assets/](assets/) - Design templates for core architecture files (TOC, security, NFRs, traceability).
- [references/](references/) - Scorecard rules, workflow guides, and shared contracts.
- [scripts/](scripts/) - Package and compilation validators.

## Package Verification
To verify the integrity of the `system-architect` skill package:
```bash
python scripts/check_skill_package.py system-architect
```
