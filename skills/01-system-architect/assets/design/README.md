# Core Design Templates

Templates used in **Design Mode** to bootstrap standard system documentation.
These are organized into typical SDD phases to avoid overwhelming output.

## Directories

- [architecture/01-global-strategy/](architecture/01-global-strategy/) - Minimal MVP initial specs (requirements, goals, problem brief).
- [architecture/03-cross-cutting/](architecture/03-cross-cutting/) - High level architecture, mechanisms, and tradeoffs.
- [architecture/02-domains/_shared-contracts/](architecture/02-domains/_shared-contracts/) - Detailed API, message, and data contracts.
- [architecture/04-delivery/](architecture/04-delivery/) - Delivery tracing, testing strategy, and roadmaps.
- [architecture/02-domains/](architecture/02-domains/) - Modules tailored for specific types of projects (Web App, API, IoT, etc.).
