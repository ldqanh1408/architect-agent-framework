# Viewpoints

[← Table of Contents]({{INDEX_PATH}}) · *System Views › Viewpoints*

## Purpose

The three registers that make view coverage checkable instead of assumed
(ISO/IEC/IEEE 42010). Every diagram page in the workspace already declares its
`viewpoint`, `stakeholders` and `concerns` in front matter; without these
registers those declarations are a field nobody joins on.

## Exists from

The `standard` level. One context with one diagram does not need a register of
viewpoints; two contexts and five diagrams do, because that is the point where
"did we draw everything" stops being answerable by looking.
